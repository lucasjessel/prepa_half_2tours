# prepa_half_2tours
Web page of the preparation plan for the Deux Tours half Ironman in La Rochelle in june 2027. 
- To save the tracking of the preparation : regularly (mensually, weekly) export the tracking in Json format. (an export / import button on the web page is needed)

- To modify / update the plan if the preparation has not started yet : replace only the index.html by the new one and push the commits.

- To adapt the plan if the preparation has already started :
  - Export the tracking before any modification
  - replace the web page by the new one (index.html) by specifying to not change the pasts sessions but only the ones to come (push the commits) 
  - import the tracking saved just before the plan modifications.
